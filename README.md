This repository contains Python code to simulate cancer population and resistance strategy dynamics under different therapy regimes and evaluate the effect of evolvability on therapy outcomes.

The graphs for the base case and the alternative case are generated in the notebook `visualize.ipynb`.

The models (G-function framework) for single, double, and combination therapy can be found in models folder.
The base model has the parameter values and some additional functions.

The G-function for the fitness landscape is in utils.

Note: During revision of the manuscript, 'facultative evolvability' was replaced with 'plastic evolvability'.
